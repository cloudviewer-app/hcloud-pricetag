# Contributing

Thanks for looking. This tool writes labels to your infrastructure with a
write-scoped token, so it is maintained by one person and **does not accept
pull requests**: every line is written and reviewed by its maintainer. Pull
requests will be closed without review; this is not a judgement of the change.

What helps instead:

- **Bugs, missing server types or prices:** open an [issue](../../issues) with
  the output of `hcloud-pricetag plan` (server names may be redacted).
- **Security issues:** never in a public issue. See [SECURITY.md](SECURITY.md).

The code is open so that you can read exactly what it does before you give it
a token, and fork it under its [license](LICENSE) if you want to change it.
